# 03 退役（retire）与销毁字节（purge）的差别

这是运行人员最容易混淆的两个操作。本培训用**磁盘状态审计**和
**`/v1/status` 字节计数**给出可核对的事实，而不是停留在字面定义。

## 一、概念对照

| 维度 | 素材退役 `POST /assets/{id}/retire` | 结果清理 `DELETE /artifacts/{id}` |
|---|---|---|
| 作用对象 | 素材（输入资产） | 渲染结果 PNG（产出物） |
| 状态变化 | `available → retired` | `live → purged` |
| PNG 字节 | **保留**在状态文件中 | **删除**（状态里 `png` 置空） |
| 身份/摘要/事实 | 全部保留 | 结果 ID、摘要、任务事实全部保留 |
| 可逆性 | 不可逆（无重新激活接口） | 不可逆（再取返回 410） |
| 对历史渲染的影响 | 无（快照持有自己的字节副本） | 已成功任务仍 `succeeded`，只是下载不到字节 |
| HTTP 取回 | 素材无独立 GET，状态可经快照/状态文件核对 | `GET /artifacts/{id}` → **410 gone** |

一句话：**退役是"标记停用但留证"，清理是"只销毁产物字节、保留任务事实"。系统没有提供任何删除素材字节的接口。**

## 二、退役后字节还在：磁盘状态审计

实验在退役后直接只读打开实例 A 的状态文件 `evidence/run/instance-a/state-a.json`，
证据 `03-retire-on-disk-state-after-retire.json`：

```json
{
  "assetId": "asset-a",
  "state": "retired",
  "digest": "fce5d44a93777695889c03941c61d7517cce82a1dc766bb2734bd2b353fe3c2d",
  "pngBytesStillPresent": 126,
  "pngSha256": "fce5d44a93777695889c03941c61d7517cce82a1dc766bb2734bd2b353fe3c2d",
  "note": "retire 只翻转 state，PNG 字节仍在状态文件中"
}
```

核对要点：

1. `state` 已是 `retired`；
2. 126 字节的 PNG 仍在，且 sha256 与源素材 `asset-a.png` 完全一致；
3. 每个冻结快照的 `assets` 闭包里还各有一份字节副本——这就是退役后旧快照能继续渲染的物质基础。

## 三、purge 销毁的是结果字节：计数与 410

清理前实例 A 有两份存活渲染结果，`artifactBytes = 12794`（= 6397 × 2）。
对基准结果 `png-00000007` 执行清理：

```sh
DELETE /v1/artifacts/png-00000007
→ 200 {"state":"purged"}
```

| 观察点 | 清理前 | 清理后 | 证据 |
|---|---|---|---|
| `status.artifactBytes` | 12794 | 6397（恰好释放一份 6397 字节 PNG） | `04b-purge-artifact-bytes-released.json` |
| `GET /artifacts/png-00000007` | 200 PNG | **410 `artifact png-00000007 was purged`** | `get-purged-artifact-410.json` |
| `GET /jobs/job-00000005` | succeeded | **仍 succeeded**，artifactId 不变 | `job-still-succeeded-after-purge.json` |
| 素材 asset-a | retired，126 字节在 | **retired，126 字节仍在** | `asset-untouched-by-purge.json` |

注意三处"保留"：

- 任务事实保留：清理不会把成功任务改成失败，审计链不断；
- 结果摘要保留：仍可凭摘要证明"曾经产出过什么"，只是取不回字节；
- 素材字节完全不受影响：purge 的代码路径只操作 `Artifacts`，不碰 `Assets`。

## 四、为什么这样设计（结合持久化规则）

- 状态以完整 JSON 原子替换落盘，素材与快照闭包内嵌字节，备份单文件即可恢复全部历史；
  若退役即删字节，所有引用该素材的历史快照会立刻失去可渲染性，历史隔离将失效。
- 结果 PNG 是可再生的派生产物（同一快照 + 同一 scale 确定性渲染），
  清理只释放空间、不丢事实；需要时可凭仍 active 的快照重新提交任务再生。
- 410 与 404 语义不同：410 表示"这个结果确实存在过，但字节已被清理"，
  404 表示实体从未存在。排障时不要把 410 当成任务失败。

## 五、动手核对

```sh
# 退役留证
python3 - <<'PY'
import json, base64, hashlib
st = json.load(open('training/evidence/run/instance-a/state-a.json'))
a = st['assets']['asset-a']
print(a['state'], len(base64.b64decode(a['png'])),
      hashlib.sha256(base64.b64decode(a['png'])).hexdigest())
# 预期：retired 126 fce5d44a93777695889c03941c61d7517cce82a1dc766bb2734bd2b353fe3c2d
PY

# 清理事实
cat training/evidence/steps/04b-purge-get-purged-artifact-410.json
cat training/evidence/steps/04b-purge-job-still-succeeded-after-purge.json
```
